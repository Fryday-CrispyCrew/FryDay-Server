# db/

Flyway 도입 전에 운영 DB에 손으로 적용하던 스키마 변경 스크립트입니다. 이력 확인용으로만 남겨 둡니다.

- `2026-08-04_add_indexes.sql` 까지는 운영 DB에 적용되어 있어 `V1__baseline.sql`(운영 스키마 덤프)에 들어 있습니다.
- `2026-09-15` ~ `2026-09-28` 그룹 스크립트는 운영에 적용되기 전에 Flyway 로 넘어와, 최종 형태로 합쳐 `V2__create_group_tables.sql` 이 되었습니다.

이후 스키마 변경은 이 폴더가 아니라 `src/main/resources/db/migration` 에 `V{번호}__{설명}.sql` 로 추가합니다.
배포할 때 애플리케이션이 기동하면서 Flyway 가 적용하므로, 운영 DB에 손으로 먼저 실행하지 않습니다.
